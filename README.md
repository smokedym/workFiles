# ВОЛС Mobile — Документация бизнес-логики

> Автоматически сгенерировано: 2026-04-22  
> Версия приложения: 0.0.7-L (Build 7)  
> Платформа: Kotlin Multiplatform (Android + iOS)

## О приложении

**ВОЛС Mobile** — мобильное приложение для полевых инспекторов, выполняющих обследование опор волоконно-оптических линий связи (ВОЛС) на воздушных линиях электропередачи. Приложение работает в режиме **offline-first**: данные хранятся локально и синхронизируются с сервером при наличии соединения.

## Ключевые бизнес-процессы (обзор)

```
Вход в систему
    └─► Загрузка данных / Синхронизация
         └─► Выбор задания
              └─► Выбор линии электропередачи
                   └─► Просмотр опор на карте
                        └─► Инспекция опоры
                             ├─► Фотофиксация (с GPS)
                             ├─► Добавление объектов ВОЛС
                             └─► Отправка на проверку
                                  ├─► Принято ✓
                                  └─► Отклонено → Редактирование → Повторная отправка
```

| Сеть | Ktor 3.4.0 |
| Карты | MapLibre Compose 0.12.1 |
| Secure Storage | KVault 1.12.0 |
| Навигация | AndroidX Navigation Compose 2.9.2 |
